
  # Portal do Acordo - Frontend

  Aplicacao web do Portal do Acordo. Ela renderiza o relatorio executivo e consome os endpoints do backend em `/api`.

  ## Comandos

  - `npm run dev`: executa localmente para desenvolvimento.
  - `npm run dev:lan`: executa liberando acesso pela rede interna.
  - `npm run build`: gera a versao de producao em `dist`.
  - `npm run preview:lan`: serve a build pela rede interna para validacao.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.
